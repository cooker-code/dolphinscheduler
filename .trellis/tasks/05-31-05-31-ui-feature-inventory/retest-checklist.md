# DolphinScheduler UI 重构回测 Checklist

> 用法：重构完成后，逐模块按此清单验证。每项有明确操作和预期结果。

---

## 一、认证 & 个人中心

- [ ] **登录 - 账密** — 输入 `admin / dolphinscheduler123`，点击登录，页面跳转到 `/home`
- [ ] **登录 - 路由守卫（未登录）** — 未登录直接访问 `/home`，自动跳转到 `/login`
- [ ] **登录 - 路由守卫（已登录）** — 已登录访问 `/login`，自动跳转到 `/home`
- [ ] **修改密码** — 进入 `/password`，填写旧密码和新密码，保存成功后旧密码无法登录
- [ ] **用户信息** — 进入 `/profile`，能查看用户名/邮箱/手机，修改邮箱保存后刷新显示新值
- [ ] **关于** — 进入 `/about`，页面正常渲染，显示版本号和许可证信息
- [ ] **UI 设置 - 暗色主题** — 切换暗色主题，所有页面背景变为深色，刷新后保持
- [ ] **UI 设置 - 语言** — 切换为英文，所有菜单和标题变为英文

## 二、项目管理

### 2.1 项目列表

- [ ] **项目列表加载** — 进入 `/projects/list`，页面显示已有项目列表（非空数据时能看到项目卡片）
- [ ] **创建项目** — 点击「创建项目」，填写名称，保存后项目出现在列表中
- [ ] **编辑项目** — 点击项目「编辑」，修改名称，保存后列表显示新名称
- [ ] **删除项目** — 点击「删除」，确认后项目从列表消失
- [ ] **搜索项目** — 输入项目名关键词，列表过滤只显示匹配项

### 2.2 项目概览

- [ ] **项目概览** — 进入 `/projects/:code`，显示任务/工作流实例状态统计图表（图表正常渲染，无空白）

### 2.3 工作流定义

- [ ] **工作流定义列表** — 进入工作流定义页，显示列表表格（有数据时能看到工作流行）
- [ ] **创建工作流 - 进入编辑器** — 点击「创建工作流」，DAG 画布正常打开
- [ ] **创建工作流 - 添加 SHELL 节点** — 从左侧面板拖拽 SHELL 任务到画布，双击弹出配置面板，填写脚本内容，保存节点
- [ ] **创建工作流 - 保存** — 点击工具栏「保存」，填写工作流名称，确认后工作流出现在列表中
- [ ] **工作流上线** — 在列表点击「上线」，状态变为「在线」
- [ ] **工作流下线** — 在列表点击「下线」，状态变为「下线」
- [ ] **工作流运行** — 上线后点击「运行」，填写运行参数，确认后在工作流实例中能看到新实例
- [ ] **工作流复制** — 点击「复制」，选择目标项目，复制成功后目标项目出现同名工作流
- [ ] **工作流导出** — 选中工作流点击「导出」，下载得到 JSON 文件
- [ ] **工作流导入** — 点击「导入」上传 JSON 文件，导入后工作流出现在列表中
- [ ] **工作流删除** — 下线后点击「删除」，确认后工作流从列表消失
- [ ] **工作流定义树形图** — 点击「树形图」按钮，页面切换为树形展示
- [ ] **定时管理 - 创建** — 点击「定时」，创建新定时，填写 Cron 表达式，保存后出现在定时列表
- [ ] **定时管理 - 上线/下线** — 对定时任务执行上线/下线操作，状态正确切换

### 2.4 工作流实例

- [ ] **工作流实例列表** — 进入实例列表，能看到历史运行记录（有数据时）
- [ ] **实例状态过滤** — 按状态（成功/失败/运行中）过滤，列表正确过滤
- [ ] **实例详情 DAG** — 点击实例进入详情，DAG 图显示节点运行状态（绿色/红色/灰色）
- [ ] **实例详情日志** — 在实例详情中点击某个任务节点，能查看该任务的执行日志
- [ ] **实例甘特图** — 点击「甘特图」，正确显示任务执行时间轴
- [ ] **实例停止** — 对运行中的实例点击「停止」，状态变为「停止」
- [ ] **实例重跑** — 对已完成实例点击「重跑」，产生新的运行实例

### 2.5 任务实例

- [ ] **任务实例列表** — 进入任务实例页，显示历史任务记录（有数据时）
- [ ] **任务日志查看** — 点击任务实例行的「日志」按钮，弹出日志查看弹窗，内容可读
- [ ] **任务停止** — 对运行中任务点击「停止」，状态变为停止

### 2.6 其他项目页面

- [ ] **项目级参数** — 进入参数页，能创建 `key=value` 的全局参数，工作流运行时可引用
- [ ] **工作流关系图** — 进入工作流关系页，显示工作流间依赖关系图（有定时依赖时）
- [ ] **全项目定时列表** — 进入 `/workflow/timings`，显示所有定时任务的状态

- [ ] **文件管理列表** — 进入 `/resource/file-manage`，显示文件/目录列表
