用户管理

管理系统用户账号、权限、授权关系。功能包含：创建用户、修改密码、授权数据源/项目、停用账号。

告警组管理

创建告警组，关联多个告警插件实例（Email / DingTalk / WeChat / Slack / 飞书）。

告警实例管理

配置具体的告警插件实例，每种插件有独立的动态配置字段（由插件 JSON Schema 驱动）。

Worker 分组管理

将注册的 Worker 节点按业务归组。任务可指定运行在特定分组（如 hdp-worker-group、spark-worker-group）。

Yarn 队列管理

管理 Yarn 资源队列，供租户绑定使用。

环境管理

配置执行环境变量（k=v 格式），绑定 Worker 分组。SQL 作业发布时可选择环境。

集群管理

管理多集群配置（适用于多集群部署模式）。

K8S 命名空间管理

配置 Kubernetes 命名空间，供 K8S 任务类型使用。

令牌管理

生成 API 访问令牌，供外部系统调用 DolphinScheduler REST API 时鉴权使用。
