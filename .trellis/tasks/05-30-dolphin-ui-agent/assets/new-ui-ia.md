# DolphinScheduler 新 UI 信息架构设计

> 设计原则：**原有功能 100% 保留，SQL-first 作为并行新入口，不替换旧 DAG 流程**
> 版本：v0.1 | 日期：2026-05-30

---

## 一、设计原则

| 原则 | 说明 |
|------|------|
| 零破坏 | 原 DAG 编辑器、工作流定义、实例监控、安全中心等全部保留原有交互 |
| 并行模式 | SQL Studio 是新增入口，与 DAG 模式并存，用户自选 |
| 渐进迁移 | 现有 DAG 工作流可"一键转为 SQL 作业"进入 SQL Studio 管理 |
| Agent 可选 | AI 辅助是增强功能，不强制，离线环境可关闭 |
| 字段完整 | 新 UI 发布流程覆盖 DS 全部原生字段，不丢失配置能力 |

### 3.2 SQL Studio（全新模块）

#### 3.2.1 SQL 作业工作台（主页面）

**左侧文件树（220px）**
- SQL 作业列表（按项目/目录分组）
- 文件状态：已上线（绿）/ 修改中（橙）/ 草稿（灰）
- 分支切换器（个人分支 / master 只读）
- 新建 SQL 作业按钮

**主编辑区**
- Monaco Editor（HQL/SQL 语法高亮）
- 行号 + Lint 告警标注
- Tab 栏（多文件切换）
- AI 辅助竖栏（生成/格式化/血缘/解释）

**底部结果面板（可折叠）**

| Tab | 功能 |
|-----|------|
| 测试结果 | 执行状态、耗时、返回行数、数据预览表格（≤1000行） |
| 解析结果 | 产出表（绿）、依赖表（蓝）、变量参数（橙） |
| 历史版本 | commit 列表，点击行 → 主区域切换为 side-by-side diff |

**右侧发布抽屉（480px）**

| 区块 | 字段 | DS 原生字段 |
|------|------|------------|
| SQL 变更预览 | 个人分支 vs master diff | — |
| 依赖解析 | 产出表、上游依赖映射、合并策略（覆盖/追加） | taskRelationJson |
| 调度配置 | Cron、数据源、Worker 组、租户、环境、优先级、执行策略、失败策略 | timing-modal 全字段 |
| 告警配置 | 告警组、通知策略、超时告警 | warningGroupId, warningType, timeout |
| 全局变量 | 从 SQL 自动解析 ${var}，可手动增删 | globalParams |
| 发布信息 | 分支流向、负责人、发布说明 | — |

#### 3.2.2 SQL 作业实例监控

- **入口**：顶部「SQL Studio」→「实例监控」
- **保留 DS 原生能力**：复用工作流实例列表，过滤只显示来自 SQL Studio 的 workflow
- **列表列**：作业名、状态、触发方式（定时/手动）、调度时间、执行耗时、运行次数
- **操作**：重新运行、故障恢复、停止/暂停、查看日志、查看 DAG（跳转原生视图）
- **甘特图**：保留原有甘特图入口

#### 3.2.3 SQL 作业定时管理

- **入口**：SQL Studio → 某作业 → 定时配置
- **功能**：查看/启用/禁用当前作业的 cron 调度
- **字段**：开始时间、结束时间、Cron 表达式、状态（ONLINE/OFFLINE）
- **复用**：底层调用原有 `timing-modal` 和 `/workflow/timing` API

#### 3.2.4 SQL 版本管理

- **入口**：底部面板「历史版本」Tab
- **功能**：
  - commit 列表（hash、message、时间、AI标注）
  - 点击 → side-by-side diff 视图（主编辑区切换）
  - 发布后展示「master 合并记录」
  - 发布记录 JSON（commit、分支、发布人、解析依赖、生成 DAG）

## 五、SQL Studio 与原有 DAG 的共用底层

SQL Studio 发布流程不绕过任何 DS 原有能力，完全复用：

```
SQL Studio 发布          原有 DAG 发布
     ↓                        ↓
SQL解析 + DAG编译              手动配置
     ↓                        ↓
WorkflowDefinitionService.createOrUpdate()   ← 同一个 API
     ↓
release() → ONLINE
     ↓
CommandService.insertCommand()
     ↓
Master → Worker → TaskPlugin(SQL)
     ↓
实例监控（工作流实例/任务实例页面）← SQL Studio 和 DAG 共用
```
